# 🥩 Sistema de Gestión Comercial para Carnicerías

¡Bienvenido al **Sistema de Gestión Comercial para Carnicerías**! Este es un sistema web robusto diseñado específicamente para la administración de carnicerías y negocios similares, permitiendo un control preciso de ventas por peso/unidad, control de inventario, arqueos de caja diarios y reportes estadísticos avanzados.

El proyecto está diseñado bajo un enfoque de **Arquitectura Limpia (Clean Architecture)** en PHP para el backend y una interfaz de usuario fluida estilo **SPA (Single Page Application)** con un diseño estético moderno basado en Glassmorphism.

---

## 🚀 Características Principales

*   **💰 Control de Caja y Jornadas:** Apertura y cierre de caja diario con registro de montos iniciales, efectivo real en caja y cálculo automático de diferencias o descuadres.
*   **🥩 Ventas Inteligentes:** Interfaz ágil para la facturación/venta de productos de carnicería, soportando venta por **peso** (kilogramos) y por **unidad**, integrando la selección de presentaciones.
*   **📦 Gestión de Stock e Inventario:** Control de inventarios en tiempo real con capacidad para registrar ingresos de mercadería y pérdidas por mermas.
*   **🏷️ Catálogo de Productos y Categorías:** Clasificación avanzada de cortes y productos (Carne Vacuna, Pollo, Cerdo, Embutidos, Productos de Granja) con diferentes presentaciones de venta.
*   **👥 Control de Usuarios y Roles:** Autenticación segura y control de accesos basado en roles (Administrador y Cajero/Vendedor) para limitar operaciones críticas.
*   **📊 Módulo de Reportes:** Visualización gráfica de estadísticas, ventas acumuladas y rendimiento mensual.
*   **💾 Respaldo y Seguridad:** Funcionalidad para generar copias de seguridad de la base de datos y exportación de reportes en PDF.
